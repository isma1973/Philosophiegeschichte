Logo, Farben, Typografie und Markenidentität des Ismail UI Frameworks.

🔷 Logo

Das Logo besteht aus dem Logo‑Mark und dem Wortzeichen „Ismail UI“.

Ismail UI clean · modular · consistent

Logo‑Regeln

  • Keine Verzerrung oder Rotation
  • Keine Farbänderungen am Logo‑Mark
  • Mindestens 0.5rem Abstand zu anderen Elementen
  • Bevorzugte Hintergründe: var(--bg), var(--bg-secondary), Weiß

🔤 Typografie

Ismail UI verwendet die Schriftart „Inter“ für maximale Lesbarkeit.

Schriftgrößen

  • h1: 32–42px
  • h2: 24–28px
  • h3: 18–20px
  • Body: 15–16px
  • Small: 12–13px

Regeln

  • Überschriften: font-weight 600
  • Buttons: font-weight 500
  • Meta‑Text: var(--text-light)

✨ Markenwerte

Die Identität von Ismail UI basiert auf fünf Kernwerten.

  • Klarheit: Keine unnötigen Elemente.
  • Modularität: Jede Komponente ist eigenständig.
  • Konsistenz: Farben, Abstände, Typo folgen einem System.
  • Produktivität: Für echte Tools, nicht Marketing.
  • Dark‑First Design: Optimiert für moderne Dashboards.

🔖 Favicon

Das Favicon basiert auf dem Logo‑Mark und ist in mehreren Größen verfügbar.

Empfohlene Größen:

  • 16×16 – Browser Tab
  • 32×32 – Retina
  • 180×180 – Apple Touch Icon
  • 192×192 – Android / PWA
  • 512×512 – High‑Res App Icon
